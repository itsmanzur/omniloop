Also included

The rest of the shop layer.

Custom index

Facet queries hit OmniLoop's table, not a pile of tax_query joins. Saving a product, term, or attribute rebuilds that row. Rebuild from Settings after you change post types.

Woo when you want it

Attributes as color, image, or size swatches. Dual price slider, stock, sale, rating, add to cart, quick view. Hide Woo facets when the module is looping posts.

ACF opt-in

Pick select, checkbox, radio, button group, or true/false fields in Settings. They index like native facets and can sit in the same sidebar.

Native Loop attach

Hand matching IDs to Divi's own loop. Main query only, unless you opt a secondary query in. Stops archive leaks onto unrelated loops.

Languages and currency

If WPML or Polylang is active, filter labels follow the shopper’s language. The price bar follows multi-currency hooks when those plugins are present. Export settings to copy a shop to staging.

Analytics

Anonymous clicks and empty-result mixes, 30 days, on the dashboard. See which facet combos die so you can add a preset or rewrite the empty state.

Why OmniLoop

The shop layer Divi’s free filter does not try to be.

Divi 5 can list posts. OmniLoop turns that list into a catalog: its own index, cards you design, merchandising, and URLs Google can read — still one Visual Builder module.

01

One module, the whole shop

Filters, grid, chips, sort, and pagination live in OmniLoop Filter. Nested Card Item children reorder image, title, price, and buttons in the layers panel. No Filter + Loop split.

02

Own index, not meta joins

Facet queries hit OmniLoop’s table. Saving a product, term, or ACF field updates that row. Rebuild once when you change post types — shops stay snappy as catalogs grow.

03

WooCommerce optional

Posts and any public post type loop on Divi + WordPress alone. Turn Woo on later for swatches, price slider, stock, sale, rating, cart, and quick view. ACF is a separate opt-in.

04

Pretty /ol/ SEO URLs

Color + shoes can look like /ol/color/navy/category/shoes/. Title, description, and H1 templates, noindex for page 2+, optional sitemap. Shareable presets with ?ol_preset=.

05

Merchandising in the same index

Pin products, push out-of-stock last, promo badges, “Only X left.” Filter Sync keeps two modules on one page. This is shop control, not just a checkbox list.

06

Divi’s Loop, OmniLoop’s speed

Already designed cards in Loop Builder? Native Loop attach hands matching IDs to Divi’s loop — main query only unless you opt in — so other loops on the page stay clean.

Also included

The rest of the shop layer.

Custom index

Facet queries hit OmniLoop's table, not a pile of tax_query joins. Saving a product, term, or attribute rebuilds that row. Rebuild from Settings after you change post types.

Woo when you want it

Attributes as color, image, or size swatches. Dual price slider, stock, sale, rating, add to cart, quick view. Hide Woo facets when the module is looping posts.

ACF opt-in

Pick select, checkbox, radio, button group, or true/false fields in Settings. They index like native facets and can sit in the same sidebar.

Native Loop attach

Hand matching IDs to Divi's own loop. Main query only, unless you opt a secondary query in. Stops archive leaks onto unrelated loops.

Languages and currency

WPML / Polylang labels, WOOMULTI-style price facets, settings export/import so a staging shop copies cleanly.

Analytics

Anonymous clicks and empty-result mixes, 30 days, on the dashboard. See which facet combos die so you can add a preset or rewrite the empty state.

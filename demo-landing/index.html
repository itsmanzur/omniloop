Setup

Three steps. Then you are filtering.

You do not write queries. You do not paste JSON. If you can add a Divi module, you can run OmniLoop.

  1. 1

    Activate OmniLoop

    Install the Divi 5 extension. Open OmniLoop → Settings and tick the post types you sell or list (Products, Posts, or both).

  2. 2

    Rebuild the index

    One click. OmniLoop copies titles, categories, and attributes into its own fast table. Saving a product later updates that row by itself.

  3. 3

    Drop OmniLoop Filter

    In the Visual Builder, insert the module. Pick a filter layout and a card style. Save, view the page, tap a filter. That is the shop.

Need WooCommerce? Turn it on whenever you are ready. Need a custom field? Tick it in Settings and rebuild once.

Why OmniLoop

Divi can list posts. This turns the list into a shop.

The free Post Filter is a list with checkboxes. OmniLoop is the catalog on top: fast filters, cards you design, merchandising, and URLs Google can read — still one Visual Builder module.

01

One module does the whole page

Filters, grid, sort, and page numbers live together. Nested Card Items let you reorder image, title, price, and buttons in the layers panel.

02

Stays fast as the catalog grows

Queries hit OmniLoop’s own index, not a stack of WordPress meta joins. Save a product — that row updates. Rebuild once when you change what you index.

03

WooCommerce is optional

Loop posts or any public type on Divi + WordPress alone. Add Woo later for swatches, price slider, stock, sale, rating, cart, and quick view.

04

Filter pages Google can read

Navy + bags can look like /ol/color/navy/category/bags/. You control title, heading, and whether page 2 is hidden from search.

05

Pin, promote, hide empty shelves

Search to pin a hero product. Push sold-out items last. Promo badges and “Only 2 left” come from Settings — no extra plugin.

06

Keep Divi’s Loop if you already designed it

Native Loop attach hands matching products to Divi’s own loop. Other loops on the page stay untouched unless you opt them in.

Also included

The rest of the shop layer.

Custom index

Facet queries hit OmniLoop's table, not a pile of tax_query joins. Saving a product, term, or attribute rebuilds that row. Rebuild from Settings after you change post types.

Woo when you want it

Attributes as color, image, or size swatches. Dual price slider, stock, sale, rating, add to cart, quick view. Hide Woo facets when the module is looping posts.

ACF opt-in

Pick select, checkbox, radio, button group, or true/false fields in Settings. They index like native facets and can sit in the same sidebar.

Native Loop attach

Hand matching IDs to Divi's own loop. Main query only, unless you opt a secondary query in. Stops archive leaks onto unrelated loops.

Languages and currency

If WPML or Polylang is active, filter labels follow the shopper’s language. The price bar follows multi-currency hooks when those plugins are present. Export settings to copy a shop to staging.

Analytics

Anonymous clicks and empty-result mixes, 30 days, on the dashboard. See which facet combos die so you can add a preset or rewrite the empty state.

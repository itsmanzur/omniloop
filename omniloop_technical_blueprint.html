২. হাই-স্পিড ডেটাবেস ও ইন্ডেক্সিং

WP_Query lag এড়িয়ে কাস্টম মেটা ইন্ডেক্স

WooCommerce বা ACF ফিল্টারিং ধীর হয় একাধিক wp_postmeta JOIN-এর জন্য। OmniLoop ইন্সটলেই লাইটওয়েট ক্যাশ টেবিল wp_omniloop_index তৈরি করবে।

Table Schema: wp_omniloop_index Engine: InnoDB 
CREATE TABLE wp_omniloop_index (
    id BIGINT(20) UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    post_id BIGINT(20) UNSIGNED NOT NULL,
    post_type VARCHAR(20) NOT NULL,
    facet_key VARCHAR(50) NOT NULL,
    facet_value TEXT NOT NULL,
    numeric_value DECIMAL(12,4) DEFAULT NULL,
    KEY idx_lookup (facet_key(20), numeric_value),
    KEY idx_post (post_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

পোস্ট সেভ হলে save_post হুক কাস্টম ফিল্ড ও ট্যাক্সোনমি মেটা প্রসেস করে এই টেবিলে ইন্ডেক্স করে।

৫. ভাইব কোডিং প্রম্পট প্লেবুক

Cursor / Claude Code দিয়ে স্টেপ-বাই-স্টেপ বিল্ড

প্রতিটি ধাপের প্রম্পট কপি-পেস্ট করে মডিউল ওয়ান-বাই-ওয়ান ডেভেলপ করুন। কপি বাটন Clipboard API ব্যবহার করে।

ধাপ ১: প্লাগইন স্কেলেটন ও অটোলোডার Prompt #1 
Create a production-ready WordPress plugin structure named "OmniLoop Engine". Use PHP 8.1+ features with PSR-4 autoloading namespace `OmniLoop\Engine`. Build a main entry file `omniloop-engine.php` and a Singleton class `App` in `app/Core/App.php` that initializes REST API routes, Divi 5 integration, and Gutenberg block registration. Keep it modular and clean.

ধাপ ২: কাস্টম ডেটাবেস ইন্ডেক্সিং ইঞ্জিন Prompt #2 
Write a PHP class `OmniLoop\Engine\Core\Indexer` that hooked into `save_post`. When a post or product is saved, extract meta values (ACF fields, WooCommerce price, taxonomy terms) and insert/update them into a custom DB table `wp_omniloop_index`. Create the dbDelta creation function inside `app/Core/Installer.php` with columns for post_id, facet_key, facet_value, and numeric_value.

ধাপ ৩: শেয়ার্ড React Custom Hook Prompt #3 
Create a React custom hook `useOmniQuery` in `src/core/useOmniQuery.js`. It should maintain state for selected filters (facets, page, search, sort), debounce inputs by 250ms, update browser URL query params via `window.history.pushState`, and execute fetch requests to `/wp-json/omniloop/v1/query`. Return { posts, facets, loading, setFilter, clearAll }.

ধাপ ৪: Divi 5 ও Gutenberg র্যাপার Prompt #4 
Implement `src/gutenberg/index.js` using `@wordpress/blocks` and `src/divi5/index.js` using `@divi/module-library`. Both components should render the FilterControls and LoopRenderer React elements by consuming our shared `useOmniQuery` hook. Ensure compatibility with Divi 5's Visual Builder React environment without throwing hydration errors.
